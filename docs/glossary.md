# Glossary

| Term | Definition |
|---|---|
| **Audit pack** | The thirteen artefacts accompanying every released output. An output without one is not a SWOS output. |
| **Blast-radius query** | An EPG traversal identifying every claim, output, memory item and downstream citation affected by a retracted or corrected source. The EPG's highest-value operation. |
| **Blind review** | Running a reviewer without prior AI suggestions or earlier verdicts in context. The control against automation anchoring. |
| **Citation laundering** | A real, correctly-cited source attached to a claim its passages do not support. Survives every check except passage-level support classification. |
| **Contract mode** | Harness operation with no system under test bound: fixture conformance is checked, quality is not measured. |
| **Coverage bias** | Retrieval favouring accessible, popular or English-language sources. |
| **Discipline pack** | Reasoning module, evidence hierarchy, proof standard, analysis moves, failure modes, rubric and acceptance test for one field. |
| **EPG** | Evidence Provenance Graph. W3C PROV-DM compatible. Answers *where from and how produced*. |
| **Epistemic type** | One of nine claim classifications, from observed fact to unverified claim. |
| **Evidence Matrix** | The atomic claim-to-source map. The only structure drafting may read from. |
| **Evidence span** | The passage-level anchor for a citation. Document-level support assertions are forbidden. |
| **Governance theatre** | Controls that exist but never block. Detected by a release history with zero blocked releases. |
| **Interpretive flattening** | Collapsing genuine interpretive ambiguity into a single safe reading. |
| **Over-association** | Linking unrelated facts into a neat but false synthesis. The dominant residual failure in long-form generated writing. |
| **Output bundle** | Manuscript plus audit pack. |
| **Provenance completeness** | Claims linked to an EPG node divided by total claims. Must be 1.0 at release. |
| **Rival reading** | A first-class argument-graph node type. Mandatory in interpretive disciplines. |
| **RPM** | Research Program Memory. Governed cross-project continuity. |
| **Rule #3** | No drafting until research plan, evidence matrix, argument graph, provenance graph and decision ledger exist. The load-bearing control. |
| **SDL** | Scholarly Decision Ledger. Append-only. Answers *why this judgement*. |
| **Scholarly State Model** | The lifecycle spine: thirteen states with transition preconditions. |
| **Supersession** | Replacing a decision or bundle while preserving the original intact. SWOS never mutates a judgement record. |
| **Waiver** | A permitted, recorded gate exception with a reason, an approver and an expiry. A waiver without all three is a policy breach. |
