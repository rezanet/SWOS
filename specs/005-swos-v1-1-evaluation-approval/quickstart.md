# Quickstart: Validate Evaluation and Human Approval

> **Historical scope note:** Use feature `007` for source-release approval and
> candidate verification. The evaluation steps below remain valid for runtime
> assurance and scholarly decision controls.

## Prerequisites

- Python environment installed from the locked development requirements.
- No provider credentials are required or read.
- A deterministic finalized run generated by the runtime test fixture.

## 1. Generate and verify a real evaluation subject

```powershell
python -m unittest tests.runtime.test_evaluation.RuntimeEvaluationTests.test_all_eight_planes_bind_one_finalized_run
```

Expected: the real work-order/finalizer path creates a run; all eight planes
name the same subject; the frozen evaluation-result schema validates.

## 2. Exercise fail-closed plane binding

```powershell
python -m unittest tests.runtime.test_evaluation
```

Expected: missing run, altered manifest/store/artifact, omitted/duplicate plane,
and fixture-only runtime claims fail.

## 3. Current source-release boundary

The former approval-pack and release-decision tests are historical. For the
current source-release record and candidate verifier, follow
`specs/007-simple-release-record/quickstart.md`. Runtime evaluation still
requires complete provenance, passing planes and truthful human judgement.

## 4. Run all deterministic gates

```powershell
python -m unittest discover -s tests/runtime -p 'test_*.py'
python -m unittest discover -s tests/prose -p 'test_*.py'
python evals/harness/run_evals.py --all --system autonomous-swos --run-dir <run-dir> --fail-on-gate
python tools/check_spec_kit_artifacts.py
python tools/validate_document_manifest.py
python tools/validate_schemas.py --strict
python tools/check_governance.py
python tools/lint_skills.py
python tools/check_host_independence.py
python tools/check_vendor_leakage.py
python tools/check_portability_acceptance.py --definitions-only
python tools/check_workflow_profiles.py
python -m ruff check swos_runtime evals tools tests/runtime
```

Expected: all deterministic checks pass; live compatibility remains manual and
non-gating.

## 5. Interpret the boundary

A sample human record in tests proves validation behavior only. It is not an
approval of a public-source project or a v1.1 release. That evidence belongs to
the next programme slice.
