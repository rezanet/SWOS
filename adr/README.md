# Architecture Decision Records

An ADR is required for anything that changes a frozen schema, adds a first-class
component, adds an agent, or changes a release gate.

## Format

Context, Decision, Consequences, Alternatives considered. Consequences include
the costs, not only the benefits - an ADR listing only advantages has not
recorded a decision, it has recorded an advertisement.
